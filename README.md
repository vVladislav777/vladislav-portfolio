# Владислав — портфолио

Персональный сайт-портфолио веб-дизайнера и разработчика лендингов. Тёмная тема, один оранжевый акцент, огромная типографика, кастомный курсор, магнитные кнопки, переходы-маски между страницами и скролл-сцены.

**Стек:** Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · Motion (Framer Motion) · GSAP + ScrollTrigger · Lenis. Контент на русском.

## Запуск

```bash
npm i
npm run dev        # http://localhost:3000
npm run build      # production-сборка
npm run start      # запуск собранной версии
npm run lint
npx tsc --noEmit
```

Превью кейсов — сгенерированные заглушки. Пересоздать их или OG-картинку:

```bash
node scripts/generate-placeholders.mjs
node scripts/generate-og.mjs
```

## Что нужно решить вам

1. **Telegram и канал.** Откройте `src/config/site.ts` и замените `username`, `https://t.me/channel` и `site.url` (домен нужен для canonical, sitemap и Open Graph).
2. **Работы.** В `src/data/works.ts` укажите реальные ссылки (`url: "#"`), проверьте тексты задач и решений. Два кейса, «Волна» и «Обжиг», придуманы: замените их своими или удалите.
3. **Скриншоты.** Положите реальные изображения в `public/works/<slug>/` с теми же именами: `cover.webp`, `alt.webp` (показывается при наведении), `1.webp`, `2.webp`, `3.webp`. Пропорции 16:11, ширина около 1600 px.
4. **Тексты услуг, выгод, FAQ и шагов работы** лежат прямо в компонентах `src/components/sections/*.tsx`: `services.tsx`, `benefits.tsx`, `process.tsx`, `faq.tsx`.
5. **Короткие видео вместо второй картинки** при наведении можно добавить в `work-card.tsx`. Сейчас видео нет, потому что нет исходников.

## Эффекты и как они устроены

Референсы: polishchukdsgn.com (центральное имя, курсор, компактные кейсы), aragoza.studio (переходы, счётчик «01 / 05»), patison10.github.io (продающая структура). Ваши скриншоты к сообщению не приложились, поэтому механики сделаны по сайтам и описанию. Тексты, код и графика свои.

- **Hero.** Каждая буква выезжает из-под маски (CSS, без ожидания JS). Рядом с курсором буква становится тоньше (вариативная ось Unbounded 250–900), приподнимается, наклоняется и окрашивается в акцент. Ширина букв зарезервирована, поэтому соседние буквы не прыгают. Фон — halftone-шейдер.
- **Курсор.** Точка и кольцо на пружине, `mix-blend-mode: difference`. На ссылках кольцо растёт, на элементах с `data-cursor="…"` становится оранжевой плашкой с подписью («Смотреть», «Написать», «Далее»). Отключается на touch-устройствах и при `prefers-reduced-motion`, тогда остаётся системный курсор.
- **Переходы страниц.** Нативный React `<ViewTransition>`: старая страница уходит вглубь, новая раскрывается маской снизу. Обложка кейса «перелетает» из карточки на страницу кейса (shared element morph).
- **Работы.** При наведении превью сменяется вторым экраном, работает липкий счётчик «01 / 05» с прокруткой цифр. На `/works` есть фильтры по типу, огромный контурный счётчик и плывущее поле точек на CSS.
- **Бегущие строки.** Скорость и направление зависят от скорости скролла. Вне экрана строки останавливаются.
- **GSAP ScrollTrigger.** Линия прогресса в «Как это работает» и параллакс галереи кейса. GSAP подгружается отдельным чанком только когда секция подходит к экрану.
- **Прочее.** Магнитные кнопки, текст кнопок «перекатывается», подчёркивание ссылок, разбор заголовков по словам, «Let's Talk» с перекатом букв и круглой магнитной кнопкой, прогресс скролла, якорная навигация с плавным скроллом Lenis, кнопка «Наверх».
- **Reduced motion.** Lenis, шейдер, параллакс, скролл-сцены, бегущие строки и курсор выключаются. Анимации Motion упрощаются (`reducedMotion="user"`), CSS-анимации и view transitions сводятся к нулю.

## Компоненты 21st.dev

MCP 21st.dev подключён, поиск работает, но **дневной лимит выдачи кода (2/2) был исчерпан**, поэтому из каталога взяты только идеи. Код написан вручную под токены сайта.

| Компонент | Что взято | Что изменено |
|---|---|---|
| **Halftone Dots / ShaderBackground** (21st.dev Shader Builder, по мотивам Paper Shaders, Apache-2.0). Код дали вы. | Скопирован в `src/components/ui/halftone-dots-led-screen.tsx` без изменений настроек | `function render` превращена в стрелочную функцию: иначе строгий TypeScript (`tsc --noEmit`) не видит проверку на null. Компонент грузится лениво (`next/dynamic`, `ssr: false`) после первого взаимодействия, лежит под затемняющим градиентом с прозрачностью 45 %, при reduced-motion не монтируется |
| Scroll Based Velocity (magicui) | Идея: бегущая строка со скоростью от скролла | Своя реализация на Motion, разделитель-ромб в цвете акцента, пауза вне экрана, reduced-motion |
| Magnetic (ibelick) | Идея магнитного притяжения | Своя реализация на пружинах Motion, только для точных указателей |
| Animated Line Accordion (shadcnspace) | Подача FAQ: подсветка активного пункта, плюс превращается в минус | Своя реализация с `aria-expanded` / `aria-controls` / `role="region"` |
| Cursor Follow (educalvolpz) / Cursor (unlumen) | Идея курсора с контекстной подписью | Своя реализация через `data-cursor`, blend-mode, отключение на touch |

Структура shadcn: `components.json`, алиасы `@/components/ui`, `@/lib/utils` (`cn`). Папка `components/ui` нужна, чтобы `npx shadcn add …` и компоненты 21st.dev ставились в предсказуемое место и импортировались одинаково.

## Решения, принятые самостоятельно

- **Тёмная тема + оранжевый `#FF5A1F`.** На тёмном фоне halftone-шейдер смотрится органично. Контраст: основной текст 16:1, приглушённый `#A6A39E` 7.6:1, акцент на фоне 6:1, тёмный текст на акценте 6:1.
- **Шрифты:** Unbounded (display, вариативный) и Golos Text (текст), оба с кириллицей, через `next/font`.
- **WebGL.** По ТЗ WebGL не используется, но шейдер вы явно попросили вставить в начало. Он двумерный (2D-фрагментный шейдер, без 3D и моделей), используется только в hero. На `/works` фон сделан на CSS.
- **Переходы на View Transitions** вместо `AnimatePresence`. В App Router exit-анимации AnimatePresence работают ненадёжно, а React 19.3 + Next 16 поддерживают `<ViewTransition>` штатно и умеют морфить обложку из карточки в кейс. В браузерах без поддержки страницы просто сменяются мгновенно.
- **Cache Components выключены.** Сайт полностью статический, а скрытые смонтированные страницы (Activity) мешают курсору и скролл-сценам.
- **Ссылка в Telegram** `https://t.me/<username>?text=…`. Текст брифа дополнительно копируется в буфер обмена на случай, если клиент Telegram не подставит его сам.
- **Цены.** На сайте нет ни одной цифры цены: только «Цена договорная», в блоке «Стоимость», FAQ и подвале. Проверено поиском по исходникам.

## Деплой

**Vercel:** импортируйте репозиторий на vercel.com, фреймворк определится автоматически, настройки по умолчанию.

**Cloudflare Pages:** проще всего через адаптер OpenNext (`@opennextjs/cloudflare`), см. документацию Cloudflare по Next.js. Сайт полностью статический, так что подойдёт и любой Node-хостинг с `npm run build && npm run start`.

После деплоя поменяйте `site.url` в `src/config/site.ts` на реальный домен.
