# Viberg — портфолио Влада

Одностраничный сайт-портфолио веб-дизайнера и разработчика. Первый экран — белый лист с «жидким» размытым словом **VIBERG** в стиле постера CHAOS, дальше чёрный фон, прозрачные «стеклянные» надписи и элементы в духе iOS 26, брутальные заголовки, видео реальных работ, курсор-баллончик, металлические кнопки и крутящаяся монета Telegram.

**Стек:** Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · Motion (Framer Motion) · Lenis · Three.js + React Three Fiber (фон первого экрана) · lucide-react. Контент на русском.

## Запуск

```bash
npm i
npm run dev        # http://localhost:3000
npm run build      # production-сборка
npm run start      # запуск собранной версии
npm run lint
npx tsc --noEmit
```

## Что нужно решить вам

1. **Telegram и канал.** В `src/config/site.ts` замените `username`, `https://t.me/channel` и `site.url` (домен нужен для canonical, sitemap и Open Graph). Там же бренд `brand: "Viberg"`.
2. **Ссылки на работы.** В `src/data/works.ts` у каждой работы `url: "#"`: подставьте адреса сайтов, когда они будут опубликованы. Там же описания, теги и длительность роликов.
3. **Новая работа.** Сожмите видео (без звука, 720p) и сделайте постер, затем добавьте объект в `works.ts`:

   ```bash
   node_modules/ffmpeg-static/ffmpeg.exe -i input.mp4 -an -vf scale=1280:-2 -c:v libx264 -preset slow -crf 30 -pix_fmt yuv420p -movflags +faststart public/videos/<slug>.mp4
   ```

   ```bash
   node_modules/ffmpeg-static/ffmpeg.exe -ss 1 -i input.mp4 -frames:v 1 -vf scale=1280:-2 -q:v 4 public/videos/<slug>.jpg
   ```

4. **Тексты.** «Обо мне» лежит в `src/components/sections/about.tsx`, FAQ в `faq.tsx`, подзаголовок первого экрана в `hero.tsx`.

## Структура страницы

1. **Hero.** Светлый лист на живом ч/б шейдере «старого телевизора»: слово VIBERG в стиле CHAOS, словарная подпись шрифтом сайта (Geist) «/viberg/ сайты, которые цепляют и приносят заявки.» и металлические кнопки.
2. **Бегущие строки.** Их скорость зависит от скролла.
3. **(01) Обо мне.** Влад, 16 лет, подход и «Что я делаю»: 4 пункта на стеклянных карточках с иконками.
4. **(02) Портфолио.** 4 работы с видео: Bavaria Motors, The Terrascape Gazette, Сосновый двор, Каштан.
5. **(03) Стоимость.** «Цена договорная», без цифр.
6. **(04) FAQ.** 4 вопроса.
7. **Let's Talk.** Монета Telegram и ссылка на канал.

## Дизайн и эффекты

- **VIBERG в стиле постера CHAOS.** SVG-текст (Geist 700, растянут через `textLength`) пропущен через SVG-фильтр: крупный низкочастотный шум (`feTurbulence`) → смещение (`feDisplacementMap`) даёт тягучие волны → размытие и порог альфы превращают края в «чернила» → второй шум как маска решает, где буквы резкие, а где расфокусированы → горизонтальный смаз-ореол. Волны медленно «дышат» (SMIL-анимация частоты и силы смещения), при reduced-motion — статика. Фон — шейдер «старого телевизора» под светлой вуалью: он запускается сам сразу после загрузки (в простое браузера) или раньше, при первом взаимодействии. Под словом подпись тем же шрифтом, что и весь сайт (Geist). Узор волн задаётся `seed` в `chaos-name.tsx`; если сменить ник или бренд, стоит проверить, что слово читается.
- **Работы как на patison10.github.io.** В карточке без звука крутится ч/б видео (играет, только пока карточка на экране) и становится цветным при наведении. Подпись «01 · ЛЕНДИНГ · 0:51», брутальное название, теги, круглая стрелка. Есть счётчик работ и фильтры «Все / Лендинг / Многостраничный». Клик открывает окно: цветное видео с управлением, описание, теги, кнопка «Хочу такой же» (Telegram с готовым текстом) и листание «1 / 4». Esc закрывает окно, стрелки листают, фокус остаётся внутри окна.
- **Палитра.** Чёрный фон, белый текст, без цветного акцента. Поверхности, чипы, «пилюли», навигация и бейджи сделаны «жидким стеклом» (утилита `glass`: полупрозрачная заливка, `backdrop-filter`, блик). Иконки с подписями лежат на таких линзах.
- **Прозрачные брутальные заголовки.** Утилита `brutal`: Geist 900, капс, плотный трекинг. Буквы залиты полупрозрачным градиентом с бликом через `background-clip: text`. На белых плашках они автоматически становятся чёрными через переменную `--ink`.
- **Навигация.** Внизу плавающая стеклянная «пилюля» «Меню / Связаться», сверху логотип VIBERG и статус «Беру проекты».
- **Курсор.** Точка с `mix-blend-difference` и «распыление» краски на canvas за движением. Над карточками рядом с точкой появляется стеклянная подпись. На touch-устройствах и при reduced-motion курсор отключается.
- **Монета Telegram.** Объёмная ч/б монета на CSS 3D: вращается, при наведении ускоряется и наклоняется к курсору, раскручивается перетаскиванием, по клику открывает Telegram.
- **Reduced motion.** Lenis, волны названия, бегущие строки, видео-превью и курсор отключаются, анимации Motion и CSS упрощаются.

## Проверка

- `npm run lint`, `npx tsc --noEmit` и `npm run build` проходят без ошибок, главная пререндерится статически.
- В браузере на 1280 и 360 px проверено: постер, видео-карточки (ч/б, цвет при наведении), окно работы (открытие, листание стрелками, Esc), меню. Консоль без ошибок.
- Видео ужаты с 81 МБ до 11 МБ суммарно.
- **Не перемерено:** Lighthouse после редизайна. Видео, Three.js и WebGL-кнопки тяжелее прежнего; перед публикацией стоит прогнать PageSpeed Insights.
