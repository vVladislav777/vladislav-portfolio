# Viberg — портфолио Влада

Одностраничный сайт-портфолио веб-дизайнера и разработчика. Первый экран — белый лист с «жидким» размытым словом **VIBERG** в стиле постера CHAOS, дальше чёрный фон, прозрачные «стеклянные» надписи и элементы в духе iOS 26, брутальные заголовки, видео четырёх проектов, курсор-баллончик, металлические кнопки и крутящаяся монета Telegram.

**Стек:** Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · Motion (Framer Motion) · Lenis · Three.js + React Three Fiber (фон первого экрана) · lucide-react. Контент на русском.

## Запуск

```bash
npm i
npm run dev        # http://localhost:3000
npm run build      # production-сборка
npm run start      # запуск собранной версии
npm run lint
npx tsc --noEmit
```

## Что нужно решить вам

1. **Telegram и канал** уже указаны в `src/config/site.ts`: @V_viberg0 и t.me/vladweb_lending_0. Там же бренд `brand: "Viberg"` и адрес сайта `site.url`.
2. **Ссылки на работы.** В `src/data/works.ts` у каждой работы `url: "#"`: подставьте адреса сайтов, когда они будут опубликованы. Там же описания, задачи, функции, теги и длительность роликов. Пока адресов нет, кнопка открывает видео и не ведёт на заглушку.
3. **Новая работа.** Сожмите видео (без звука, 720p) и сделайте постер, затем добавьте объект в `works.ts`:

   ```bash
   node_modules/ffmpeg-static/ffmpeg.exe -i input.mp4 -an -vf scale=1280:-2 -c:v libx264 -preset slow -crf 30 -pix_fmt yuv420p -movflags +faststart public/videos/<slug>.mp4
   ```

   ```bash
   node_modules/ffmpeg-static/ffmpeg.exe -ss 1 -i input.mp4 -frames:v 1 -vf scale=1280:-2 -c:v libwebp -quality 75 public/videos/<slug>.webp
   ```

4. **Условия.** Уточните состав пакетов: число страниц, сценарии бота, интеграции, правки, оплату, поддержку и расходы на хостинг/домен. На сайте нет выдуманных гарантий, фиксированных сроков или скидок.

5. **Тексты.** «Обо мне» лежит в `src/components/sections/about.tsx`, FAQ в `faq.tsx`, подзаголовок первого экрана в `hero.tsx`.

## Структура страницы

1. **Hero.** Сохранены шейдер и жидкий VIBERG. H1 — название Viberg. По просьбе владельца подзаголовок и описание убраны; «Обсудить проект» и «Смотреть работы» оформлены одинаковыми металлическими кнопками.
2. **(01) Портфолио.** Все четыре проекта сохранены. Тип, задача, реализованные функции, видео-просмотр и фильтры. Описание функций основано на существующих данных проектов; результатов продаж и клиентских отзывов нет.
3. **(02) Услуги.** Лендинг, многостраничный сайт, редизайн; обращение в Telegram с выбранной услугой.
4. **(03) Процесс.** Обсуждение → план → дизайн → разработка и проверка → запуск.
5. **(04) Стоимость.** Цены предоставлены владельцем: лендинг от 10 000 ₽; лендинг + бот 15 000 ₽; многостраничник 20 000 ₽. Состав работ и итоговая стоимость согласуются до старта; у редизайна нет выдуманной цены.
6. **(05) Обо мне.** Дизайн, разработка и запуск; прямое общение с исполнителем. Возраст не используется как главный аргумент.
7. **(06) FAQ.** Цена, сроки, материалы и запуск. Убраны неподтверждённые обещания срока 2–3 недели и бесплатной поддержки 14 дней.
8. **Контакты.** Монета, текстовая ссылка «Обсудить проект», подсказка для первого сообщения и канал.

Новые разделы используют существующие шрифты, стекло и отступы. Новые компоненты 21st.dev не добавлялись. Проект не переписывался.

## Дизайн и эффекты

- **VIBERG в стиле постера CHAOS.** SVG-текст (Geist 700, растянут через `textLength`) пропущен через SVG-фильтр: крупный низкочастотный шум (`feTurbulence`) → смещение (`feDisplacementMap`) даёт тягучие волны → размытие и порог альфы превращают края в «чернила» → второй шум как маска решает, где буквы резкие, а где расфокусированы → горизонтальный смаз-ореол. Волны медленно «дышат» (SMIL-анимация частоты и силы смещения), при reduced-motion — статика. Фон — шейдер «старого телевизора» под светлой вуалью: он запускается сам сразу после загрузки (в простое браузера) или раньше, при первом взаимодействии. Под словом заголовок и описание тем же шрифтом, что и весь сайт (Geist). Узор волн задаётся `seed` в `chaos-name.tsx`; если сменить ник или бренд, стоит проверить, что слово читается.
- **Работы как на patison10.github.io.** В карточке без звука крутится ч/б видео (играет, только пока карточка на экране) и становится цветным при наведении. Подпись «01 · ЛЕНДИНГ · 0:51», брутальное название, теги, круглая стрелка. Есть счётчик работ и фильтры «Все / Лендинг / Многостраничный». Клик открывает окно: цветное видео с управлением, описание, теги, кнопка «Обсудить мой проект» (Telegram с готовым текстом) и листание «1 / 4». Esc закрывает окно, стрелки листают, фокус остаётся внутри окна.
- **Палитра.** Чёрный фон, белый текст, без цветного акцента. Поверхности, чипы, «пилюли», навигация и бейджи сделаны «жидким стеклом» (утилита `glass`: полупрозрачная заливка, `backdrop-filter`, блик). Иконки с подписями лежат на таких линзах.
- **Брутальные заголовки.** Утилита `brutal`: Geist 900, капс, плотный трекинг, сплошной белый цвет.
- **Навигация.** Внизу плавающая стеклянная «пилюля» «Меню / Обсудить проект», сверху логотип VIBERG и статус «Беру проекты».
- **Курсор.** Точка с `mix-blend-difference` и «распыление» краски на canvas за движением. Над карточками рядом с точкой появляется стеклянная подпись. На touch-устройствах и при reduced-motion курсор отключается.
- **Монета Telegram.** Объёмная ч/б монета на CSS 3D: вращается, при наведении ускоряется и наклоняется к курсору, раскручивается перетаскиванием, по клику открывает Telegram.
- **Reduced motion.** Lenis, волны названия, бегущие строки, видео-превью и курсор отключаются, анимации Motion и CSS упрощаются.

## Деплой

Сайт опубликован на GitHub Pages: **https://vvladislav777.github.io/vladislav-portfolio/**

- Каждый пуш в `main` автоматически пересобирает и выкладывает сайт (workflow `.github/workflows/deploy.yml`, вкладка Actions в репозитории). Обычно это занимает 1–2 минуты.
- Сборка для Pages — статический экспорт Next.js в папку `out/` с префиксом пути `/<имя репозитория>`. Он включается переменной `GITHUB_PAGES=true`, поэтому локальные `npm run dev` и `npm run start` работают как обычно.
- Пути к файлам из `public/` в коде нужно собирать с `process.env.NEXT_PUBLIC_BASE_PATH` (как в `src/data/works.ts`), иначе на Pages они не найдутся. Ссылки через `Link` и `router` Next.js префиксует сам.
- Локально собрать как на Pages: `GITHUB_PAGES=true PAGES_BASE_PATH=/vladislav-portfolio npm run build` (в Git Bash на Windows перед командой добавьте `MSYS_NO_PATHCONV=1`).
- Свой домен: добавьте его в Settings → Pages → Custom domain и поменяйте `site.url` в `src/config/site.ts`. Если сайт будет в корне домена, уберите префикс: в workflow поставьте `PAGES_BASE_PATH: ""`.
